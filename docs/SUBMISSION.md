# GNOME Extensions submission history

NexTile is distributed through [GitHub Releases](https://github.com/erikleblansch/NexTile/releases/latest). Publication on extensions.gnome.org is no longer planned. Use the [README installation instructions](../README.md#install) to install or update the extension.

Version **0.7.1** was submitted to extensions.gnome.org and [rejected on 5 November 2026](https://extensions.gnome.org/review/77910/). The reviewer cited AI-generated code and linked GNOME's AI and best-practice guidelines. Passing runtime tests and matching a Shexli baseline did not establish compliance with those requirements.

Version **0.7.2** is a GitHub release. It incorporates the new-window launch feature and does not claim GNOME approval. It is not a resubmission or a claim that the review objections have been resolved.

The [original preparation guide](https://github.com/erikleblansch/NexTile/blob/v0.7.1/docs/SUBMISSION.md), [historical reviewer notes](submission/REVIEWER-NOTES.md), listing artwork and original analyzer report remain available as historical records. Their preparation-time wording does not describe the current distribution status.

The automated checks remain useful for development: see [validation](VALIDATION.md), [compatibility](COMPATIBILITY.md) and the [current Shexli assessment](SHEXLI.md). They are not certification by GNOME.
